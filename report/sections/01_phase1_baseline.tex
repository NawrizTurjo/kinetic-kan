\section{Baseline Recipe and Evaluation Protocol}
\label{sec:phase1}

The baseline stage reproduces the base paper's KAN-ODE recipe
\cite{koenig2024kanode} on the Lotka-Volterra predator-prey system,
\begin{equation}
\dot u_1 = \alpha u_1 - \beta u_1 u_2, \qquad \dot u_2 = \delta u_1 u_2 - \gamma u_2,
\qquad (\alpha,\beta,\gamma,\delta) = (1.5,\,1.0,\,3.0,\,1.0),
\label{eq:lv}
\end{equation}
using a two-layer Kolmogorov-Arnold Network, $[2,10,2]$, with $G=5$
Gaussian radial-basis-function grid points per edge (240 parameters),
trained on $t\in[0,3.5]$ (36 points) and scored strictly on $t\in(3.5,14.0]$
(105 unseen points, approximately four limit-cycle periods). Extrapolation is
scored this way, on points the training loss never touched, because it is
the only meaningful test of whether the network learned the underlying
dynamics rather than memorized the shape of the training window; a model
that only reproduces the 36 training points could still be badly wrong
about the system it is meant to describe.

A parallel Susceptible-Infected-Recovered (SIR) compartmental epidemic model
and a damped-pendulum system were carried forward as the project's two
additional test systems, chosen for a specific reason beyond simply adding
more benchmarks: both have closed-form governing equations that are
textbook-simple and well understood, so that if training fails on either
one, the failure can be attributed to the architecture or the optimization
process itself rather than to an ambiguous, hard-to-verify target dynamics.
SIR additionally has a real algebraic invariant (its three compartments sum
to a constant), and the pendulum has a real, correctly-known asymptotic
equilibrium -- both properties later sections lean on directly
(Sections~\ref{sec:phase2} and \ref{sec:track-d}).

This stage established the project's evaluation protocol and the two metrics
used throughout this report. Model selection uses minimum
\emph{training}-window loss only, never by inspecting performance on the
extrapolation window; the reported error is the mean squared error (MSE)
between the model's predicted trajectory and the true trajectory, computed
strictly outside the training horizon, so that a number cannot improve simply
by widening what counts as fit. The coefficient of determination, $R^2$,
reports the same comparison on a scale where $1$ is a perfect match and $0$
is no better than predicting the mean of the true trajectory; a negative
value means the model performs worse than that trivial baseline. Every
subsequent study in this report inherits this protocol unchanged.
